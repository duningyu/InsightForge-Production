## [U1] 用户确认的设计方向
2026-09-15 本次对话：零证据初学者也能开始；从 idea 获得具体判断动作；支持 AI coding 的范围拆解、用户验收和结果返回；PRD 不再作为主流程的最终价值。用户明确要求独立的工作区主线规则和技术路线。

## 采用与新增的区分
保留项包括现有项目、IdeaBrief、方案与用户选择、Snapshot、文档、正式 Handoff、账号隔离、异步生成、额度与恢复能力。
新增设计包括三种项目目的、首次行动、最小开发任务、PROTOTYPE_TASK 与 FORMAL_HANDOFF 的边界、结果提交／复核／下一步判断。采用这些对象前应先检查工作区是否已有等价能力，不按文档名称重复建表或服务。

## 技术路线不依赖新的市场断言
本次没有把“用户会付费”“状态化引导一定优于通用 AI”“低频产品必然成功”等判断写成事实。项目收费、留存和竞争优势均保留为待验证假设；无需为了执行本路线安装新工具、迁移框架或接入指定供应商。

所有技术版本、供应商配置与运行成本以实际环境和当时官方说明为准。测试报告只引用后续实际执行结果，不能继承历史文档的通过数字。
